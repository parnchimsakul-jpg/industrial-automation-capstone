# Fusion CAD Project Directory

## Guidelines
- **Software**: Autodesk Fusion (Fusion 360)
- Store local archives, exports, and shared drawings here.

## Subdirectories
- `exports/`: STEP, IGES, STL (for 3D printing test jigs), and DXF files (for laser cut blanks).
- `archive/`: Older revisions and superseded models.

## Recommended File Naming
- Assemblies: `ASM_BoxFolder_Main_v<rev>.step`
- Folding Tools / Fingers: `PART_FoldingBlade_v<rev>.step`
- Blanks: `DXF_BoxBlank_Pattern_v<rev>.dxf`
