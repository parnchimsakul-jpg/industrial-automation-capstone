# GX Works3 PLC Directory

## Environment
- **Software**: Mitsubishi GX Works3
- **Primary Language**: Ladder Logic (LD) / Structured Text (ST) / FBD

## Organization
- `gxworks3_project/`: Place the `.gx3` project folder and program files here.
- `io_mapping/`: Contains [io_mapping.md](file:///c:/capstone%20project/plc/io_mapping/io_mapping.md) for tracking physical sensor/actuator addresses and software labels.
- `backups/`: Save milestone backups before modifying sequences (e.g., `BoxFolder_YYYYMMDD_v1.gx3`).
