# SMT Production Line Systems

## Stations
1. **Automatic Loader**: `ZB2535SBJ`
2. **Solder Paste Printer**: `ZB-4535LYS`
3. **Pick & Place**: `WS-8Y` (8-Head Chip Mounter)
4. **Reflow Oven**: `ZBRF-835` (Multi-Zone Hot-Air)
5. **AOI Inspection**: `ZB-800A` (2D Vision Inspection)
6. **Dispensing Robot**: Delta DRS Series SCARA
7. **Automatic Unloader**: `ZB2535XBJ`

## Integration Documents
- `smema_wiring/`: SMEMA standard interface pinouts, inter-station handshake circuits.
